📖 Chapter 1 — What Is OOP & Why It Matters

Ano ang OOP at bakit ito mahalaga?

In Object-Oriented Programming, your program is built from objects — just like real life: things have attributes and can perform actions 🧩

Sa OOP, ang programa ay binubuo ng mga bagay — parang totoong buhay: may katangian at kakayahan

Class = Blueprint / Design → like an architectural drawing
Object = Instance → the actual house built from that design

Klase = plano | Bagay = ang aktuwal na ginawa mula sa plano

The Four Pillars of OOP:

Ang apat na haligi ng OOP — pundasyon ng malinis na programa
  • Encapsulation — Keep data safe; protect it behind controlled access Pagtatago — ilihim at protektahan ang impormasyon
  • Inheritance — Reuse and extend; add new features without rewriting existing code Pagmamana — gamitin ang mayroon na, dagdagan nang bago
  • Polymorphism — Many forms; same name, different behavior Maraming anyo — parehong tawag, ibang ginagawa
  • Abstraction — Show only what's needed; hide complex inner details Pagpapayak — ipakita lang ang kailangan, itago ang masalimuot

📖 Chapter 2 — Classes & Objects: The Foundation 🏠

Klase at Bagay — ang pinakapundasyon

Defining a Class:

Gumawa ng klase — ang iyong plano 
// Class = Blueprint
public class Person {
    // Fields — data stored inside each object
    String name;
    int age;

    // Constructor — runs automatically when creating a new object
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // Method — what the object can do
    public void introduceYourself() {
        System.out.println("I am " + name + ", " + age + " years old.");
    }
}
Katangian — datos | Konstruktor — awtomatikong tumatakbo | Paraan — kakayahan ng bagay

Creating Objects:

Gumawa ng mga bagay mula sa klase 
public class Main {
    public static void main(String[] args) {
        // Create two separate instances
        Person person1 = new Person("Maria", 25);
        Person person2 = new Person("Juan", 30);

        person1.introduceYourself(); // I am Maria, 25 years old.
        person2.introduceYourself(); // I am Juan, 30 years old.
    }
}
💡 Constructor = the creation doorway
• Same name as the class
• Has no return type (no void)
• This is where you set initial values Pangalan katulad ng klase • Walang ibinabalik • Dito nagsisimula ang lahat

📖 Chapter 3 — Encapsulation: Safeguard Your Data 🔒

Encapsulation — pagtatago at pagprotekta sa datos

Don't let data be changed directly — keep it behind a controlled door; access only through approved methods ✅

Huwag hayaang basta-basta mabago — sa pamamagitan lang ng paraan makakapasok 
public class Product {
    // Private — hidden from outside access
    private String name;
    private double price;

    // Constructor
    public Product(String name, double price) {
        this.name = name;
        setPrice(price); // always validate through setter ✅
    }

    // Getter — safely read the value
    public String getName() {
        return name;
    }

    // Setter — update WITH validation ✅
    public void setPrice(double price) {
        if (price >= 0) {
            this.price = price;
        } else {
            System.out.println("Price cannot be negative! ⚠️");
        }
    }

    public double getPrice() {
        return price;
    }
}

Using it:

Product bread = new Product("Bread", 15.50);
System.out.println(bread.getName()); // Bread ✅
bread.setPrice(-5.0); // Price cannot be negative ⚠️
System.out.println(bread.getPrice()); // 15.50 — unchanged ✅
ModifierWho Can Access
public Everyone
private Only inside this class ✅ — use this for fields!
(no modifier) Within the same package
Pampubliko — lahat | Pribado — sariling klase lang | Walang nakasulat — sa loob ng parehong pakete

📖 Chapter 4 — Inheritance: Build on What Exists 🌳

Inheritance — pagmamana; huwag ulitin, magpalawak

Don't copy-paste the same code — inherit it! Add only what's new ✨

Huwag muling isulat ang parehong code — magmana, tapos magdagdag ng bago 
// Parent — general, shared traits
public class Person {
    protected String name;
    protected int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void greet() {
        System.out.println("Hello, I am " + name);
    }
}

// Child — inherits, adds its own
public class Student extends Person {
    private String course;

    // Call parent constructor FIRST
    public Student(String name, int age, String course) {
        super(name, age); // important! ✅
        this.course = course;
    }

    public void showCourse() {
        System.out.println(name + " is studying " + course);
    }
}

Using it:

Student ana = new Student("Ana", 20, "Computer Science");
ana.greet();      // Hello, I am Ana ✅ — inherited!
ana.showCourse(); // Ana is studying Computer Science ✅
💡 Key Keywords:
• extends → establishes inheritance
• super() → calls parent's constructor
• protected → visible to children even in other files extends = nagmamana | super = tawagin ang magulang | protected = nakikita ng anak

📖 Chapter 5 — Polymorphism: Many Forms 🔄

Polymorphism — magkakaibang gawi sa iisang tawag

Method Overriding — Change Inherited Behavior:

Palitan ang galaw ng namang paraan 
public class Person {
    public void speak() {
        System.out.println("Hello!");
    }
}

public class Student extends Person {
    @Override // ← explicit reminder: we are changing behavior ✅
    public void speak() {
        System.out.println("Hi! I'm still learning.");
    }
}

public class Teacher extends Person {
    @Override
    public void speak() {
        System.out.println("Good day! Let's begin.");
    }
}

See it in action:

Person[] people = {
    new Person(),
    new Student(),
    new Teacher()
};

for (Person p : people) {
    p.speak(); // each responds differently ✅
}
// Hello!
// Hi! I'm still learning.
// Good day! Let's begin.

Method Overloading — Same Name, Different Input:

Parehong pangalan, iba ang tinatanggap 
public class Calculator {
    // Same method name — different parameters
    public void display(int number) {
        System.out.println("Number: " + number);
    }

    public void display(String text) {
        System.out.println("Message: " + text);
    }

    public void display(double amount) {
        System.out.printf("Amount: %.2f%n", amount);
    }
}

📖 Chapter 6 — Abstraction: Hide Complexity 🎭

Abstraction — itago ang masalimuot, ipakita ang kailangan lang

Abstract Class — Partial Blueprint:

Klase na mayroon at wala pang laman — dapat tapusin ng anak 
public abstract class Vehicle {
    // Has implementation — shared
    public void startEngine() {
        System.out.println("Engine started...");
    }

    // No implementation — child MUST provide ✅
    public abstract void drive();
}

public class Car extends Vehicle {
    @Override
    public void drive() {
        System.out.println("Driving a car — steering wheel & four wheels.");
    }
}

Interface — Pure Contract:

Kasunduan — walang laman, lahat dapat gawin ng gumagamit 
public interface Flyable {
    void fly(); // any class using this MUST implement ✅
}

public class Airplane implements Flyable {
    @Override
    public void fly() {
        System.out.println("Flying high in the sky ✈️");
    }
}

📖 Chapter 7 — Complete Example: Store System 🛒

Halimbawa — ilapat ang lahat sa sistema ng tindahan

Putting it all together — a working foundation:

// Product — fully encapsulated
public class Product {
    private String name;
    private double price;

    public Product(String name, double price) {
        this.name = name;
        this.price = price;
    }

    public String getName() { return name; }
    public double getPrice() { return price; }
}

// Person — base class
public class Person {
    protected String name;
    public Person(String name) { this.name = name; }
    public String getName() { return name; }
}

// Customer — inherits from Person
public class Customer extends Person {
    private double money;

    public Customer(String name, double money) {
        super(name);
        this.money = money;
    }

    public boolean buy(Product item) {
        if (money >= item.getPrice()) {
            money -= item.getPrice();
            System.out.println(name + " bought " + item.getName());
            return true;
        }
        System.out.println(name + " doesn't have enough money");
        return false;
    }
}

Run the program:

public class Main {
    public static void main(String[] args) {
        Product coffee = new Product("Coffee", 35.0);
        Customer lito = new Customer("Lito", 50.0);
        
        lito.buy(coffee); // Lito bought Coffee ✅
    }
}
