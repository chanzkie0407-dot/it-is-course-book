📖 Chapter 1 — What Is Backend?

Ano ang Backend?

Frontend = what user sees & clicks (HTML/CSS/JS)
Backend = what happens behind the scenes — stores data, checks rules, connects to database

Harap — nakikita ng tao • Likod — gumagawa ng trabahong hindi nakikita
💡 Simple Analogy: Restaurant 🍽️
Frontend = Dining area — what customers see
Backend = Kitchen — cooks, stores, manages orders
Database = Pantry — keeps ingredients & records
API = Waiter — carries orders between front & back Harap = kainan • Likod = kusina • Imbakan = lalagyan • API = tagahatid ng utos

Why Node.js? 🟢

Bakit Node.js?
  • Same language — JavaScript! — front & back in one language ✅ Parehong wika — hindi kailangang matuto ng bago
  • Fast — built on Chrome's V8 engine
  • Huge ecosystem — npm = thousands of ready-made tools
  • Express — lightweight & popular framework for web servers

📖 Chapter 2 — Setup Your Environment

Ihanda ang kompyuter

1. Install Node.js

Go to nodejs.org → download LTS version → install → next next finish ✅

Check it works — open terminal/Command Prompt:

node -v
# Should show: v20.x.x or similar ✅

npm -v
# Should show version number ✅

2. Make Your Project Folder

mkdir my-first-server
cd my-first-server
npm init -y
# Creates package.json — your project settings & list of tools

3. Install Express

npm install express
# Express is now in node_modules/ ✅
my-first-server/
├── node_modules/ ← installed tools
├── package.json ← project info
├── package-lock.json ← exact versions
└── server.js ← your code file ✅

📖 Chapter 3 — Your First Server

Ang iyong unang serber

Write server.js

// 1. Import Express
const express = require('express');
const app = express();

// 2. Port — where your server listens
const PORT = 3000;

// 3. A simple route — home page
app.get('/', (req, res) => {
  res.send('🎉 Hello from your own server!');
});

// 4. Start listening
app.listen(PORT, () => {
  console.log(`✅ Server running at http://localhost:${PORT}`);
});

Run It! 🚀

node server.js
# Open browser → http://localhost:3000
# Shows: 🎉 Hello from your own server! ✅
💡 Press Ctrl+C to stop server in terminal
Change code → stop → run again to see updates Baguhin ang code → itigil → patakbuhin ulit

📖 Chapter 4 — Routes & HTTP Methods

Daanan at uri ng utos

Routes = paths your server responds to. HTTP Method = type of action.

MethodActionCommon Use
GETReadView page, fetch data
POSTCreateSubmit form, add new record
PUTUpdateChange existing data
DELETEDeleteRemove record

More Routes Example

// About page
app.get('/about', (req, res) => {
  res.send('📋 This is my first backend server!');
});

// Dynamic route — with parameter
app.get('/user/:name', (req, res) => {
  const name = req.params.name;
  res.send(`👋 Hello, ${name}!`);
});

// Try: http://localhost:3000/user/Juan
// Shows: 👋 Hello, Juan! ✅

📖 Chapter 5 — JSON & APIs

JSON — wika ng pagpapalitan

APIs send/receive data in JSON format — easy for both humans and computers to read.

// Send JSON data
app.get('/api/products', (req, res) => {
  const products = [
    { id: 1, name: 'Laptop', price: 35000 },
    { id: 2, name: 'Mouse', price: 850 },
    { id: 3, name: 'Keyboard', price: 1200 }
  ];
  res.json(products);
});

Visit /api/products → clean data ready for your frontend! ✅

Receive Data — POST Request

Tumanggap ng impormasyon

First, tell Express to read form/JSON data:

// Add at top of server.js
app.use(express.json());
app.use(express.urlencoded({ extended: true }));

// Receive data
app.post('/api/greet', (req, res) => {
  const name = req.body.name || 'Guest';
  res.json({ message: `Hello, ${name}! ✅` });
});

📖 Chapter 6 — Connect to Database (MySQL)

Ikonekta sa imbakan

Install MySQL Driver

npm install mysql2

Connect Your Server

const mysql = require('mysql2/promise');

// Create connection
const db = mysql.createPool({
  host: 'localhost',
  user: 'root',          // your MySQL username
  password: 'your-pass', // your MySQL password
  database: 'my_database'
});

// Test route — get users
app.get('/api/users', async (req, res) => {
  try {
    const [rows] = await db.query('SELECT * FROM users');
    res.json(rows);
  } catch (err) {
    res.status(500).json({ error: err.message });
  }
});
✅ Full Flow:
Browser → Express Route → MySQL Query → JSON Response → Browser Displays Data Buong pagdaloy — mula pindot hanggang sagot

📖 Chapter 7 — Serve Static Files (Frontend)

Ihain ang pahina mula sa serber

Let your server serve your HTML/CSS/JS files:

// Add after imports
app.use(express.static('public'));

// public/ folder structure:
// public/
//   ├── index.html
//   ├── style.css
//   └── script.js

// Now http://localhost:3000/index.html loads your page ✅

📖 Chapter 8 — Middleware: What It Is

Middleware — tagapamagitan

Middleware = code that runs before your route — check, log, or modify requests.

// Log every request
app.use((req, res, next) => {
  console.log(`${new Date()} → ${req.method} ${req.url}`);
  next(); // pass to next step
});

// Example output:
// 2026-10-23 → GET /api/products ✅

ProblemFix
