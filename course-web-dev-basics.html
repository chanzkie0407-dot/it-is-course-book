📖 Chapter 1 — How the Web Works

Paano gumagana ang World Wide Web

Three languages — one team! Every website you visit uses these together:

Tatlong wika — nagtutulungan! Lahat ng website ay ginagamit ang mga ito nang sabay:
📄 HTML — Structure
The skeleton: headings, paragraphs, images, buttons
What you see Ang balangkas: pamagat, talata, larawan, pindutan — ang nakikita mo
🎨 CSS — Style
The beauty: colors, fonts, spacing, layout, mobile design
How it looks Ang anyo: kulay, font, espasyo, disenyo — kung paano ito lumalabas
⚡ JS — Behavior
The action: buttons that do things, forms that respond, live updates
How it works Ang kilos: pindutang gumagana, pormularyong tumutugon — kung paano ito kumilos

Your First Page — 3 Steps:

Ang iyong unang pahina — sa 3 hakbang:
  1. Open Notepad → Save As Buksan ang Notepad → I-save Bilang
  2. File name: index.html → Save as type: All Files Pangalan ng file: index.html → Uri: Lahat ng File
  3. Double-click it — opens in your browser! ✅ I-double-click — bubukas sa iyong browser!

📖 Chapter 2 — HTML: Build the Structure

HTML: Bumuo ng balangkas at nilalaman

HTML uses tags — words inside angle brackets. Most have an opening and closing tag.

Gumagamit ng mga <tag> — salita sa loob ng panaklong. Karamihan ay may pambungad at pangsara. 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Website</title>
</head>
<body>
    <!-- ← This is a comment — invisible! -->
    <h1>Hello! I Built This! 🎉</h1>
    <h2>This is a smaller heading</h2>
    <p>This is a paragraph. Write anything here.</p>
    <p>New paragraph starts on new line.</p>
    <!-- Links -->
    <a href="https://google.com">Click me to go to Google</a>
    <!-- Image -->
    <img src="photo.jpg" alt="Description of photo" width="300">
    <!-- List -->
    <h3>My Favorite Things:</h3>
    <ul>
        <li>Learning code 💻</li>
        <li>Good food 🍜</li>
        <li>Friends & family ❤️</li>
    </ul>
</body>
</html>
💡 Tag Cheat Sheet
Madaling Talaan ng Mga Tag <h1> = biggest heading → <h6> smallest
pinakamalaki hanggang pinakamaliit na pamagat <p> = paragraph
talata <a href="url"> = link
tugnay / link <img src="file" alt=""> = image (no closing tag!)
larawan — walang kailangang pangsarang tag <ul> = bullet list, <ol> = numbered list tuldok na talaan / may bilang na talaan

📖 Chapter 3 — CSS: Make It Beautiful

CSS: Pagandahin ang iyong pahina

Add style — 3 ways: in a <style> block, separate file, or directly. We start with the style block.

Tatlong paraan: sa loob ng pahina, hiwalay na file, o direkta. Magsisimula tayo sa loob ng pahina. 
<head>
    <style>
        /* Whole page */
        body {
            background-color: #f0f9ff; /* light blue */
            font-family: Arial, sans-serif;
            margin: 40px;
            line-height: 1.6;
        }
        /* By tag name */
        h1 {
            color: #0369a1;
            text-align: center;
        }
        /* By class — reusable! */
        .card {
            background: white;
            padding: 20px;
            border-radius: 12px;
            box-shadow: 0 2px 8px rgba(0,0,0,0.1);
            margin: 15px 0;
        }
        /* By ID — unique only once */
        #intro {
            font-size: 1.2em;
            border-left: 4px solid #0ea5e9;
            padding-left: 15px;
        }
        /* Hover effect */
        a {
            color: #0284c7;
            text-decoration: none;
        }
        a:hover {
            color: #0369a1;
            text-decoration: underline;
        }
    </style>
</head>
<body>
    <h1>My Styled Page</h1>
    <p id="intro">This paragraph has special styling.</p>
    <div class="card">
        <h3>Card Title</h3>
        <p>Content inside a nice box ✨</p>
    </div>
</body>

Responsive Design — Works on Phones Too

Disenyong umaangkop — gumagana rin sa cellphone 
@media (max-width: 600px) {
    body {
        margin: 15px; /* Less space on small screens */
    }
    .card {
        padding: 12px;
    }
}

That code says: "If screen is smaller than 600px, do this instead." ✅

Ibig sabihin: "Kung mas maliit ang screen sa 600px, gamitin ang ganitong sukat."

📖 Chapter 4 — JavaScript: Make It Interactive

JavaScript: Bigyan ito ng kakayahang tumugon

React to clicks, calculate, change content — all without reloading the page!

Tumugon sa pagpindot, magkalkula, magbago ng laman — nang hindi kailangang i-refresh ang pahina! 
<body>
    <h1>JS Demo</h1>
    <!-- Button -->
    <button id="myBtn" style="padding:10px 20px;font-size:16px;cursor:pointer">
        Click Me!
    </button>
    <!-- Where answer appears -->
    <p id="output" style="margin-top:15px;font-size:18px"></p>
    <script>
        // Find the button and output
        const btn = document.getElementById('myBtn');
        const output = document.getElementById('output');
        // Count variable
        let count = 0;
        // What happens on click
        btn.addEventListener('click', function() {
            count++; // Add 1
            output.textContent = `You clicked ${count} times! 🎉`;
        });
    </script>
</body>

Simple Calculator

Payak na Tagapagkalkula 
<input type="number" id="num1" placeholder="First number">
<input type="number" id="num2" placeholder="Second number">
<button onclick="addNumbers()">Add ✅</button>
<p id="result"></p>
<script>
function addNumbers() {
    // Get values from boxes
    const n1 = Number(document.getElementById('num1').value);
    const n2 = Number(document.getElementById('num2').value);
    
    // Calculate
    const sum = n1 + n2;
    
    // Show result
    document.getElementById('result').textContent = 
        `Answer: ${n1} + ${n2} = ${sum}`;
}
</script>

📖 Chapter 6 — Put It Online! (Free & Easy)

Ilathala sa internet — Libre at Madali!

Your page lives on your computer now — let's share it with the world!

Nasa iyong kompyuter pa lamang ito — ibahagi na natin sa iba!
  1. Go to github.com → Create free account Pumunta sa github.com → Gumawa ng libreng akawnt
  2. Click New Repository → Name: my-portfolio Pindutin ang Bagong Repositoryo → Pangalan: my-portfolio
  3. Check "Add a README" → Create Repository Tsekang "Magdagdag ng README" → Lumikha
  4. Click uploading an existing file → Drag your index.html Pindutin ang pag-upload ng file → I-drag ang iyong index.html
  5. Scroll down → Commit changes Pumunta sa ibaba → I-save ang pagbabago
  6. Go to Settings tab → Scroll to Pages (left sidebar) Pumunta sa Mga Setting → Hanapin ang Pahina sa gilid
  7. Source: main → Save → Wait 1–3 minutes Pinagmulan: main → I-save → Maghintay ng 1–3 minuto
  8. Refresh → Your link appears! ✅ I-refresh — lalabas na ang iyong link!
🎉 You're Live! Anyone with your link can see your page from anywhere! Nakapaskil ka na! Kahit saan, makikita ng sinumang may link ang iyong pahina
