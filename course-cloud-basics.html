📖 Chapter 2 — Prepare Your Project for Cloud

Ihanda ang proyekto — pinakamahalagang hakbang

Before uploading — fix your project structure! ⚠️

1. Create .gitignore — Keep Secrets Safe 🔒

Huwag isama ang mga lihim na file

Create a file named .gitignore in your main folder:

# Don't upload these!
node_modules/
.env
.DS_Store
*.log

2. .env File — Environment Variables

Itago ang mga susi at numero — hindi kasama sa code 
# .env — keep private!
PORT=3000
DATABASE_URL=your-db-connection-string
GROQ_API_KEY=your-groq-key-here

# Access in code:
require('dotenv').config();
const port = process.env.PORT || 3000;
⚠️ Never commit .env to GitHub! — Set these values in Render/Vercel dashboard instead ✅ Huwag kailanman i-upload ang .env — ilagay sa loob ng website ng serbisyo

3. package.json — Start Script

{
  "name": "my-project",
  "main": "server.js",
  "scripts": {
    "start": "node server.js"
  }
}

4. Listen Correctly

// ❌ Don't hardcode port
app.listen(3000);

// ✅ Use environment variable
const PORT = process.env.PORT || 3000;
app.listen(PORT, () => console.log(`Live on port ${PORT}`));

📖 Chapter 3 — Git & GitHub: Upload Your Code

Ipadala ang code sa GitHub — dito makikita ng iba

Git = version control; GitHub = where to store it online.

# Initialize Git (once per project)
git init

# Check files
git status

# Add all files
git add .

# Save changes
git commit -m "Initial deploy"

# Link to GitHub (create empty repo first)
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git
git branch -M main
git push -u origin main

Refresh GitHub → your code is there! ✅ Buksan ang pahina — nandoon na ang lahat

📖 Chapter 4 — Deploy Frontend to Vercel/GitHub Pages 🌐

Ilagay ang website sa internet

Option A: GitHub Pages — Simplest ✅

  1. All files in main branch
  2. Go to repo → Settings → Pages
  3. Source: Deploy from a branch → /root → Save
  4. Wait 1–3 minutes → Live at: username.github.io/repo-name/

Option B: Vercel — Faster, Automatic ✅

  1. Sign up at vercel.com → Connect GitHub
  2. Import your repo → Click Deploy
  3. Done! Live URL: your-project.vercel.app
  4. Push to GitHub → updates automatically ✨ Bawat pagbabago — nag-i-update agad sa sarili nito

📖 Chapter 5 — Deploy Node.js Backend to Render ⚡

Ilagay ang serber sa internet — tumatakbo 24/7

Render = free platform for Node/Python backends.

Steps:

  1. Sign up: render.com → Connect GitHub
  2. Dashboard → New → Web Service
  3. Select your backend repo
  4. Fill in:
Build Command: npm install
Start Command: npm start
Runtime: Node
Plan: Free ✅
  1. Under Environment Variables → Add your keys:
Key: PORT            Value: 3000
Key: DATABASE_URL    Value: (from Neon — next chapter)
Key: GROQ_API_KEY    Value: your-key-here
  1. Click Deploy → Wait 2–5 minutes 🕐
  2. Live URL: your-project.onrender.com 🎉
💡 Free Render instances "sleep" if unused — first load may take 30–60 seconds. That's normal! ✅ Unang bukas — medyo mabagal, normal lang iyon sa libreng bersyon

📖 Chapter 6 — Cloud Database: Neon PostgreSQL 🗄️

Pangmatagalang imbakan sa internet — hindi nawawala

Local database disappears when computer off — Neon gives you live, cloud-hosted database.

Setup:

  1. Sign up: neon.tech → Create Project
  2. Get Connection String → copy it ✅
  3. Paste into Render Environment as DATABASE_URL
  4. Update your code to use this URL

Test Connection:

const { Pool } = require('pg');
require('dotenv').config();

const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
  ssl: { rejectUnauthorized: false } // required for Neon
});

pool.query('SELECT NOW()', (err, res) => {
  if (err) console.error('DB Error:', err);
  else console.log('✅ DB Connected:', res.rows[0].now);
});

📖 Chapter 7 — Connect Everything Together 🔗

Pag-ugnayin ang lahat — nagtutulungan na sila

Update your frontend so it talks to the LIVE backend, not localhost!

// Before (local only):
const API_URL = 'http://localhost:3000';

// After (works everywhere!):
const API_URL = 'https://your-project.onrender.com';

// Example:
fetch(`${API_URL}/api/todos`)
  .then(res => res.json())
  .then(data => console.log(data));
