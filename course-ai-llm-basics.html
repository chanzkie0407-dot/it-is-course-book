📖 Chapter 1 — What Is LLM? Simple Explanation

Ano ang LLM?

LLM = Large Language Model — computer system trained on huge amount of text. Learns patterns → predicts next word → writes, explains, answers ✅

Sistemang natuto sa bilyong pahina — nakukumpleto ang pangungusap, sumasagot, nagpapaliwanag
💡 Not magic — it's pattern matching! 🧠
Trained on billions of pages → completes sentences, explains, answers. It doesn't truly "understand" — but it's extremely good at following patterns! Hindi ito mahika — natuto lang ito sa napakaraming teksto at sinusunod ang nakitang ayos

How It Works — 3 Steps:

Paano ito gumagana — 3 hakbang
  1. Input/Prompt — your text: "Explain JavaScript simply" Ang iyong tanong o utos
  2. Processing — model calculates most likely next words Pinipili ang pinakaangkop na susunod na salita
  3. Output — generates response, word by word Lumalabas ang sagot, salita-sa-salita

📖 Chapter 3 — Connect to AI from Node.js

Ikonekta ang AI sa iyong serber

In your backend project folder:

# Install Groq SDK
npm install groq-sdk

# Install dotenv (protects your key)
npm install dotenv

Create .env file:

GROQ_API_KEY=your-key-here-from-groq
PORT=3000

Your AI Route — server.js:

require('dotenv').config();
const express = require('express');
const { Groq } = require('groq-sdk');
const app = express();
app.use(express.json());

const groq = new Groq({
  apiKey: process.env.GROQ_API_KEY
});

// AI Chat Endpoint
app.post('/api/chat', async (req, res) => {
  try {
    const { message } = req.body;
    const response = await groq.chat.completions.create({
      model: 'llama-3-8b-8192', // fast & free model ✅
      messages: [
        { role: 'system', content: 'You are a helpful, friendly assistant. Explain simply.' },
        { role: 'user', content: message }
      ],
      temperature: 0.7, // 0=strict, 1=creative
      max_tokens: 1024
    });
    res.json({
      reply: response.choices[0].message.content
    });
  } catch (err) {
    console.error(err);
    res.status(500).json({ error: 'AI connection failed' });
  }
});

app.listen(3000, () => console.log('✅ Server running'));

Run → send POST to /api/chat → you'll receive an AI reply! 🎉 Patakbuhin → magpadala ng tanong → sasagot agad ang AI

📖 Chapter 4 — Prompt Engineering: Write Better Instructions

Paano sumulat ng magandang tanong

The quality of the answer depends on your question! ✍️

Bad vs Good Prompt:

❌ Bad✅ Good
"Explain photosynthesis""Explain photosynthesis simply for a 10-year-old. Use bullet points. Keep it under 5 sentences."
"Write code""Write a simple JavaScript function to calculate total price including 12% VAT. Add comments."

Golden Rules:

  • 🎯 Be specific — say who it's for, how long, what format Tukuyin kung para kanino, gaano kahaba, anong ayos
  • 📄 Give examples — "Format: [time] — [name]: [message]"
  • 🔄 Iterate — if not right, add details or rephrase
  • 🎭 Assign role — "Act as a helpful teacher..."

📖 Chapter 5 — Frontend Chat Interface

Pahina kung saan makakausap ang AI

Make a simple page where you can type and see replies appear:

<!-- public/chat.html -->
<!DOCTYPE html>
<html>
<body style="max-width:600px; margin:2rem auto; padding:0 1rem;">
  <h1>🤖 AI Assistant</h1>
  <div id="chatArea" style="height:400px; overflow-y:auto; border:1px solid #ddd; padding:1rem; margin-bottom:1rem; border-radius:8px;"></div>
  <input type="text" id="userInput" placeholder="Ask anything..." 
    style="width:70%; padding:.75rem; border-radius:6px; border:1px solid #ccc;">
  <button onclick="sendMessage()" 
    style="padding:.75rem 1.5rem; background:#8b5cf6; color:white; border:none; border-radius:6px; cursor:pointer;">
    Send ✅
  </button>
  <script>
    async function sendMessage() {
      const input = document.getElementById('userInput');
      const msg = input.value.trim();
      if (!msg) return;
      // Show your message
      addMessage('You', msg);
      input.value = '';
      // Send to backend
      const res = await fetch('/api/chat', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ message: msg })
      });
      const data = await res.json();
      addMessage('AI', data.reply);
    }
    function addMessage(sender, text) {
      const area = document.getElementById('chatArea');
      area.innerHTML += `<p><strong>${sender}:</strong> ${text}</p>`;
      area.scrollTop = area.scrollHeight;
    }
  </script>
</body>
</html>

Open in browser → ask anything → instant reply! ✅ Buksan sa browser — magtanong — sasagot agad

📖 Chapter 6 — RAG: Let AI Use YOUR Knowledge 📚

Gamitin ang sarili mong impormasyon

RAG = Retrieval-Augmented Generation — let AI answer from YOUR notes/documents!

How It Works:

  1. Upload your docs → split into small pieces Hatiin ang teksto sa maliliit na bahagi
  2. Convert to numbers = Embeddings — like a "fingerprint" of the text
  3. When asked → find the most relevant piece from your docs Hanapin ang pinakaangkop na bahagi
  4. Send to AI: "Answer using ONLY this info: [excerpt] + Question: [question]"
  5. Answer comes from YOUR data! ✅

Simple Implementation:

// Your stored knowledge
const knowledgeBase = [
  { topic: 'VAT', content: 'VAT in Philippines is 12%.' },
  { topic: 'MinWage', content: 'Davao Region minimum wage: ~₱585/day as of 2026.' }
];

function findRelevantContext(query) {
  return knowledgeBase.filter(item => 
    item.topic.toLowerCase().includes(query.toLowerCase()) ||
    item.content.toLowerCase().includes(query.toLowerCase())
  ).map(item => item.content).join(' ');
}

// In your prompt:
const context = findRelevantContext(userMessage);
const finalPrompt = `Use only this info: ${context}. Question: ${userMessage}`;

📖 Chapter 7 — Ethics & Responsible Use

Tamang paggamit — maging responsable
  • 🔒 Privacy — never send personal/sensitive data to public APIs Huwag magpadala ng pribadong impormasyon
  • ✅ Verify — AI isn't always correct! Double-check important answers Hindi laging tama — suriin lalo na sa mahahalagang bagay
  • ⚖️ Fairness — AI may carry biases from its training data
  • 📝 Originality — use as help, not as unmodified work submitted as your own Gamitin bilang tulong — huwag ipasa nang walang pagbabago
