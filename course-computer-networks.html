📖 Chapter 1 — What Is a Network?

Ano ang Network?

A network = two or more computers connected together to share resources — files, printers, messages, internet.

Dalawa o higit pang kompyuter na magkakakonekta — nagpapalitan ng impormasyon at kagamitan

By Size — 3 Main Types

Ayon sa sakop — tatlong uri
NameFull NameCoverageExample
LANLocal Area NetworkOne building/roomHome Wi-Fi, school lab
MANMetropolitan Area NetworkOne cityCity government network
WANWide Area NetworkCountries/continentsThe Internet 🌍
LAN = bahay/paaralan • MAN = buong lungsod • WAN = buong mundo

📱 💻 🖨️ ← LAN (Home/Office)

↓ Internet ↓

🗄️ Server — Another Country — Your Phone

Connection Methods

Paraan ng pagkakakonekta
  • Wired (Ethernet) — cable, faster, stable, less interference Gumagamit ng kawad — mas mabilis at matatag
  • Wireless (Wi-Fi / Bluetooth) — convenient, mobile, slightly slower Walang kawad — maginhawa, medyo mas mabagal

📖 Chapter 2 — How the Internet Works

Paano gumagana ang Internet

The Internet = massive global network of networks. No single owner — thousands of companies & organizations manage it together.

Napakalaking pagkakakonekta — walang nagmamay-ari, pinamamahalaan ng maraming kumpanya

Client-Server Model

Paano nag-uusap — Kliyente at Serber

Every time you visit a website, this happens:

  1. Your device = Client → asks for data Ang iyong kompyuter — humihingi ng impormasyon
  2. Remote computer = Server → has the data → sends it back Malayong kompyuter — may impormasyon at nagpapadala pabalik
  3. Data travels through cables, satellites, fiber optics — across cities or oceans
  4. Your browser receives it → displays the page ✅
💡 Simple Analogy: Ordering Food 🍔
You = Client
Restaurant = Server
Phone line = Internet
Menu = Website page
Your request → Kitchen prepares → Delivery brings it to you ✅ Parang pag-order — ikaw ang humihingi, sila ang naghahanda at nagpapadala

📖 Chapter 3 — IP Addresses & DNS

IP Address at DNS — paano naghahanap

IP Address — "Where You Live" 🏠

Every device connected to internet has a unique number = IP Address.

Natatanging numero — parang tirahan ng kompyuter sa internet 
Example: 142.250.185.142  → Google's IP
  • IPv4 — 4 groups of numbers (e.g., 192.168.1.1) — most common
  • IPv6 — longer, letters + numbers — more addresses for everyone
  • Private IP — inside your home only (192.168.x.x, 10.x.x.x) Sa loob lang ng bahay — hindi nakikita sa labas
  • Public IP — visible to the whole internet Nakikita ng lahat sa internet

DNS — "Phonebook of the Internet" 📖

Computers use numbers — humans use names. DNS translates them!

Taga-salin — pangalan → numero ng IP 
You type: google.com
↓ DNS looks it up
IP Address: 142.250.185.142
↓ Connect to that IP
Page loads! ✅

Without DNS, you'd have to type numbers every time — hard to remember! 😅

📖 Chapter 4 — Protocols: The Rules of Conversation

Protokolo — panuntunan sa pag-uusap

Computers follow standards so they understand each other = Protocols.

Parehong wika at paraan — nauunawaan ng magkakaibang kagamitan

Key Protocols You Should Know

Mahahalagang Protokolo
ProtocolFull NamePurpose
TCP/IPTransmission Control Protocol / Internet ProtocolBasic rules — how data is split, sent, and reassembled
HTTP / HTTPSHypertext Transfer ProtocolWeb pages — HTTPS = secure (lock icon 🔒)
FTPFile Transfer ProtocolSend/receive files between computers
SMTP / IMAPEmail ProtocolsSend and receive email

How Data Travels — Packet Switching

Paano naglalakbay ang impormasyon — hinahati sa maliliit na bahagi 
Big file → cut into small pieces = PACKETS
Each packet takes its own path to destination
Arrive in any order → put back together → you see the file ✅

If one path is busy, packets take another — internet keeps working! ✅

URL at Port — bahagi ng tirahan sa internet

  https://  example.com  :  443  /  page.html  ?  id=123
     ↓          ↓          ↓        ↓            ↓
  Protocol    Domain      Port     Path      Parameters
  (rules)    (who)       (door)  (where)   (extra info)

Common Ports

Madalas ginagamit na Port — parang pinto
  • Port 80 → HTTP (regular web)
  • Port 443 → HTTPS (secure web) 🔒
  • Port 21 → FTP (file transfer)
  • Port 25 → Email sending

📖 Chapter 6 — Network Devices

Mga kagamitan sa Network
  • Modem — translates internet signal from provider to your home Tagapagsalin — mula sa linya patungo sa bahay
  • Router — shares internet to all devices; manages traffic; firewall Tagapamahala — naghahati sa koneksyon sa lahat ng kagamitan
  • Switch — connects wired devices in one building
  • Access Point — adds Wi-Fi to a wired network
  • Repeater/Extender — boosts signal to reach far areas Pampalakas — umaabot sa malalayong bahagi

📖 Chapter 7 — Network Security Basics

Seguridad — protektahan ang iyong koneksyon

Common Threats ⚠️

Mga panganib
  • Malware — harmful software: virus, worm, trojan, ransomware Nakakapinsalang programa — sumisira o nagnanakaw
  • Phishing — fake emails/sites stealing passwords/info Pekeng mensahe — kunwari ay mapagkakatiwalaan
  • Man-in-the-Middle — public Wi-Fi eavesdropping
  • DDoS — flood traffic → website crashes

Protection ✅

Paano mag-ingat
  • 🔒 Encryption — scramble data so only intended receiver understands it Palihim na wika — tanging tatanggap lang ang makakaunawa
  • 🔥 Firewall — filter incoming/outgoing traffic — block suspicious connections Pader — humaharang sa mga kahina-hinalang koneksyon
  • 🛡️ Authentication — passwords, 2FA — verify who you are
  • 🏠 Secure Wi-Fi — WPA2/WPA3 only; change default router password!
  • 📱 Be Careful on Public Wi-Fi — don't do banking without VPN

📖 Chapter 8 — Hands-On: Check Your Connection

Subukan sa sariling kompyuter

Useful Commands (Windows)

Press Win+R → type cmd → Enter

Ipasok sa utos ng kompyuter 
# See your IP address
ipconfig
# Test connection to Google
ping google.com
# See path data takes
tracert google.com
✅ What You'll See:
• IP Address — your home network address
• Ping — time in milliseconds (ms) → lower = faster ⚡
• Tracert — each "hop" = one device your data passes through Mas mababang ms = mas mabilis na koneksyon
