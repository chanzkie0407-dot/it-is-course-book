📖 Chapter 1 — What Is NetBeans?

Ano ang NetBeans?

NetBeans is an IDE = Integrated Development Environment — everything you need in one place: writing code, running it, finding errors, and organizing projects 💻

Ang lahat ng kailangan mo nasa iisang lugar — pagsusulat, pagpapatakbo, paghahanap ng mali
💡 Why use an IDE instead of Notepad?
• Code is color-coded → easy to see different parts
• Automatic help → suggests and completes names
• Instant warnings → red dots show you syntax errors right away
• One button → run your program immediately
• Organized view → all your files listed clearly on the side May kulay ang code • may tulong agad • may babala kung may mali • isang pindutan lang • maayos ang lahat

📖 Chapter 3 — Create & Run a Project 🆕

Gumawa at patakbuhin ang proyekto

New Project:

Bagong proyekto — hakbang-hakbang
  1. File → New Project (or Ctrl+Shift+N)
  2. Category: Java → Project: Java Application → Next
  3. Project Name: YourProjectName → no spaces
  4. Main Class: yourprojectname.Main → filled automatically
  5. Finish ✅

Running Your Code:

Patakbuhin — alamin ang mga pindutan
  • ▶️ Green Arrow — Run Project F6 → run the whole project
  • ▶️ Smaller Arrow — Run File Shift+F6 → run only the current file
  • 🔨 Hammer — Build F11 → prepare everything, check for errors
  • 🛑 Red Square — Stop Ctrl+F2 → halt execution
💡 Tip: Make sure the correct project is selected on the left — the active one appears in bold ✅ Tingnan kung naka-bold ang tamang proyekto bago pindutin ang Run

📖 Chapter 4 — Editor Signals: What They Mean 🚦

Mga senyales sa editor — huwag balewalain!

NetBeans gives you instant feedback — learn what to look for!

SignalMeaningAction
🔴 Red squiggle in gutter Error on this line — will NOT run! Read the message → fix immediately
⚠️ Yellow triangle Warning — will run but could be better Fix when you can
💡 Lightbulb in gutter NetBeans has a suggestion Click it — auto-fix available!
Red underline Misspelled or missing name Check spelling & capitalization
Greyed-out text Unused or disabled code Remove if unnecessary
Pula = hindi tatakbo • Dilaw = babala • Bombilya = may mungkahi 
// Example — something's wrong:
System.out.println("Hello) 
// ↑ red squiggle — missing quote and semicolon
// Fixed:
System.out.println("Hello"); 
// ✅ red mark disappears

📖 Chapter 6 — Debugging: Find Problems Step-by-Step 🔍

Debugging — hanapin ang mali nang dahan-dahan

If results are wrong and unclear — use the Debugger to watch your program run!

How to Use It:

Paano gamitin ang debugger — hakbang-hakbang
  1. Click the gutter next to line number → red dot appears 🔴 = Breakpoint
  2. Click Debug Project 🐞 (or Ctrl+F5)
  3. Program pauses at that line — inspect every variable's value
  4. Step Over ⏭️ F8 → run next line, move forward slowly
  5. Step Into ⬇️ F7 → go inside a method to see its code
  6. Stop 🛑 Ctrl+F2 when finished
public class Main {
    public static void main(String[] args) {
        int a = 5;
        int b = 3;
        int c = a + b; // ← set breakpoint here
        System.out.println(c);
    }
}

When paused — you'll see: a=5, b=3 → crystal clear whether correct!

Makikita mo ang halaga ng bawat numero habang tumatakbo — madaling malaman kung tama

📖 Chapter 7 — Managing Projects & Files 📁

Pamamahala sa proyekto at file

Add a New Class/File:

Magdagdag ng bagong klase
  1. In Projects window → right-click your project name
  2. New → Java Class
  3. Name: ClassName → start with capital letter ✅
  4. Finish

Rename Properly (Refactor):

Magbago ng pangalan — huwag manu-mano, gamitin ang Refactor

Don't just edit the name directly — do it the right way:

  1. Right-click the class name → Refactor → Rename
  2. Type new name → Next → Do Refactor ✅
    3. Updates everywhere automatically — nothing missed!

Remove a Project:

Tanggalin ang proyekto

Right-click project → Delete → choose whether to remove files from disk or just from list ✅

📖 Chapter 8 — Common Problems & Quick Fixes ⚠️

Mga karaniwang problema at solusyon
ProblemPossible CauseSolution
"Main class not found" Wrong project selected or missing main method Select correct project (bolded), verify main exists
Other classes not recognized Unsaved files or wrong names Ctrl+S → F11 (Build) → F6 (Run)
Red marks but code looks correct Not saved or built recently Save → right-click project → Clean and Build
Slow startup Too many open projects Close unused projects
"Access Denied" message Previous run still active Press 🛑 Stop before running again
Hindi nakita ang klase → i-save at i-build • Mabagal → isara ang hindi ginagamit • Nakatigil → pindutin ang Stop
