📖 Chapter 1 — Introduction & Setup

Panimula at paghahanda

Expo = tool that makes mobile development easy — no complex setup, one code runs on both Android & iOS ✅

Ang Expo ay nagpapadali ng paggawa ng app — hindi kailangan ng masalimuot na paghahanda

What You Need:

Ano ang kailangan mo?
  • Laptop — Windows, macOS, or Linux ✅ Laptop — kahit anong sistema
  • Phone — Android or iPhone (optional: install Expo Go app for free from store) Telepono — opsyonal; i-download ang libreng Expo Go app
  • Node.js — LTS version (you already have this from Backend Module!) Node.js — mayroon ka na mula sa nakaraang modyul

Install & Start:

I-install at patakbuhin 
# Terminal / Command Prompt
npm install -g create-expo-app

# Create new project
npx create-expo-app MyFirstApp
cd MyFirstApp

# Run it!
npx expo start

Scan the QR code using the Expo Go app on your phone → your app opens instantly! ✅

I-scan ang QR code gamit ang Expo Go sa iyong telepono — bubukas agad ang app
MyFirstApp/
├── App.js ← your main code ✏️
├── app.json ← app settings & info
├── package.json ← dependencies & scripts
└── assets/ ← images, icons, sounds

📖 Chapter 2 — Components: Build Your UI

Mga Bahagi — bumuo ng anyo ng app

Mobile apps use special built-in components — not regular HTML tags!

Hindi HTML ang ginagamit — sariling mga bahagi ng React Native 
import { StatusBar } from 'expo-status-bar';
import { StyleSheet, Text, View } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <Text style={styles.text}>📱 Hello from your first app! ✅</Text>
      <StatusBar style="auto" />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#eff6ff',
    alignItems: 'center',
    justifyContent: 'center',
  },
  text: {
    fontSize: 20,
    color: '#1d4ed8',
  }
});

Common Components:

Mga madalas gamiting bahagi
ComponentPurpose
<View> Container — like a box/divider for layout Lalagyan — parang kahon o panghati
<Text> Display text — REQUIRED; plain text won't work directly! Teksto — kailangan ito; hindi pwedeng diretsahang isulat
<Button> Tap/clickable button Pindutan — maaaring pindutin
<TextInput> Type input — forms, login, messages Lugar para magsulat — porma o pag-login
<Image> Show pictures or icons Larawan — magpakita ng litrato
<ScrollView> Scrollable content when long Nagagulong pahina — kapag mahaba ang nilalaman

📖 Chapter 3 — State: Make It Interactive

Estado — gawing tumutugon ang app 
import { useState } from 'react';
import { View, Text, Button, StyleSheet } from 'react-native';

export default function App() {
  // count = holds the data, setCount = updates it
  const [count, setCount] = useState(0);

  return (
    <View style={styles.container}>
      <Text style={styles.num}>{count}</Text>
      <Button title="➕ Add" onPress={() => setCount(count + 1)} />
      <View style={{marginVertical: 10}} />
      <Button title="➖ Subtract" onPress={() => setCount(count - 1)} />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {flex: 1, alignItems: 'center', justifyContent: 'center', gap: 15},
  num: {fontSize: 48, fontWeight: 'bold', color: '#2563eb'}
});

Press a button → value updates → screen refreshes automatically ✅

Pindutin ang pindutan → nagbabago ang numero → nagbabago rin ang nakikita sa screen

📖 Chapter 4 — Navigation: Move Between Screens

Paglalipat — pumunta sa iba't ibang pahina

First install the navigation library:

npm install @react-navigation/native @react-navigation/native-stack
npx expo install react-native-screens react-native-safe-area-context

Two-Screen Setup Example:

Halimbawa — dalawang pahina 
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import HomeScreen from './screens/HomeScreen';
import DetailsScreen from './screens/DetailsScreen';

const Stack = createNativeStackNavigator();

export default function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator initialRouteName="Home">
        <Stack.Screen name="Home" component={HomeScreen} />
        <Stack.Screen name="Details" component={DetailsScreen} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}

From HomeScreen, navigate to DetailsScreen:

<Button 
  title="View Details"
  onPress={() => navigation.navigate('Details')}
/>
Tumawag sa navigate para pumunta sa ibang pahina

📖 Chapter 5 — Connect to Your Backend API

Kumonekta sa iyong Backend API 
import { useState, useEffect } from 'react';
import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  const [data, setData] = useState([]);

  useEffect(() => {
    // Use YOUR computer's IPv4 address — NOT 'localhost'
    fetch('http://192.168.X.X:3000/api/todos')
      .then(res => res.json())
      .then(json => setData(json))
      .catch(err => console.log('Error:', err));
  }, []);

  return (
    <View style={styles.container}>
      <Text style={styles.title}>📋 My Tasks</Text>
      {data.map((item, idx) => (
        <Text key={idx}>• {item.task}</Text>
      ))}
    </View>
  );
}
💡 Use your IPv4 address (run ipconfig in Command Prompt) — phone and emulator cannot see 'localhost' properly ✅ Gamitin ang IPv4 — hindi localhost — para makita ng telepono ang iyong server

📖 Chapter 6 — Local Storage: Works Offline

Pag-iimbak sa telepono — gumagana kahit walang internet 
import AsyncStorage from '@react-native-async-storage/async-storage';

// Save data to phone
const saveTask = async (task) => {
  await AsyncStorage.setItem('lastTask', task);
};

// Load data from phone
const loadTask = async () => {
  const value = await AsyncStorage.getItem('lastTask');
  if (value !== null) setTask(value);
};

Data stays saved on your device — still there when you reopen the app ✅

Naiimbak sa telepono — hindi nawawala kahit isara ang app
