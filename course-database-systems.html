📖 Chapter 1 — What Is a Database?

Ano ang Database?

A database is organized, reliable storage for information — not just a plain list, but structured, connected, and fast to search 💾

Ito ay maayos na imbakan — hindi basta listahan, mabilis hanapin at hindi madaling mawala
💡 Why not just use a text file or Excel?
• Blazing-fast searches — even with millions of records ⚡
• Safe & consistent — prevents conflicting changes
• No duplicates — data is stored once and reused
• Always available — survives computer restarts Mas mabilis, mas ligtas, hindi nauulit — ito ang dahilan kung bakit ginagamit ito sa lahat ng sistema

Main Types of Databases:

Dalawang pangunahing uri
  • Relational (SQL) — organized into tables with relationships ✅ (this is what we'll learn)
  • NoSQL — document or collection-based; great for large, rapidly-changing data Iba't ibang ayos — ang Relational ay pinakaangkop para sa karamihan ng sistema

📖 Chapter 2 — Structure of a Relational Database 📋

Ang ayos ng talahanayan at ugnayan

Table = Talahanayan

Like an Excel sheet — made of rows and columns:

Parang Excel — may hanay at haligi, pero mas malakas at maayos
idnamecategoryprice
1CoffeeDrink35.00
2BreadFood15.50
3EggFood8.00
  • Column — one type of info: name, price, category Haligi — uri ng impormasyon
  • Row — one complete record: Coffee, 35.00 Hanay — isang buong tala
  • Primary Key — unique ID number (id), never repeats ✅ Pangunahing Susi — walang kapareha, tumutukoy sa tala
  • Foreign Key — links to the primary key in another table Pangalawang Susi — nag-uugnay sa ibang talahanayan

📖 Chapter 3 — SQL: The Language of Databases ⌨️

SQL — ang wika ng database

Structured Query Language — the standard way to ask questions, add, change, or remove information

Ito ang utos na nauunawaan ng lahat ng database — MySQL, SQLite, PostgreSQL

The Four Core Commands (CRUD):

Apat na pangunahing gawain
OperationSQL KeywordMeaning
CreateINSERTAdd new record
ReadSELECTSearch / retrieve data
UpdateUPDATEModify existing data
DeleteDELETERemove a record

Search — SELECT:

/* Get everything from Products */
SELECT * FROM Product;

/* Specific columns only */
SELECT name, price FROM Product;

/* With a condition */
SELECT * FROM Product WHERE category = 'Food';

/* Sorted by price — lowest first */
SELECT * FROM Product ORDER BY price ASC;

/* More expensive than 20 */
SELECT * FROM Product WHERE price > 20;

Add — INSERT:

INSERT INTO Product (name, category, price)
VALUES ('Milk', 'Drink', 45.00);

Change — UPDATE:

UPDATE Product
SET price = 38.00
WHERE name = 'Coffee';
/* ⚠️ NEVER forget WHERE — without it, EVERY row changes! */

Remove — DELETE:

DELETE FROM Product
WHERE name = 'OldItem';
/* ⚠️ Note: no * — table name only */

📖 Chapter 4 — Relate & Combine Tables 🔗

Pag-ugnayin ang mga talahanayan

Don't repeat data — use separate tables and link them!

Huwag ulit-ulitin — hiwalay na talahanayan, pinag-uugnay gamit ang susi

Bad — Duplicating Data:

sale_idnamecategoryprice
1CoffeeDrink35
2CoffeeDrink35

Good — Separated & Linked ✅:

Table 1: Category

idname
1Drink
2Food

Table 2: Product

idnamecategory_idprice
1Coffee135
2Milk145
3Bread215

Bring Them Together — JOIN:

SELECT Product.name, Category.name AS type, Product.price
FROM Product
JOIN Category ON Product.category_id = Category.id;

Result: Coffee | Drink | 35 — clean, no duplicates! ✅ Lalabas ang buong impormasyon nang hindi inuulit — maayos at madaling baguhin

📖 Chapter 5 — Set Up Your Database 💻

Ihanda ang database sa iyong kompyuter

We'll use SQLite — free, zero setup, single file, no server needed!

Pinakamadali — isang file lang, walang kailangang i-install na server

Steps:

  1. Download DB Browser for SQLite (free)
  2. Click New Database → name it: Shop.db
  3. Go to the "Execute SQL" tab
  4. Paste the code below → Run ✅
-- Create tables
CREATE TABLE Category (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL
);

CREATE TABLE Product (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    price REAL NOT NULL,
    category_id INTEGER,
    FOREIGN KEY (category_id) REFERENCES Category(id)
);

-- Insert sample data
INSERT INTO Category (name) VALUES ('Drink'), ('Food');
INSERT INTO Product (name, price, category_id) VALUES 
('Coffee', 35.00, 1),
('Milk', 45.00, 1),
('Bread', 15.50, 2);

📖 Chapter 6 — Connect with Java 🔌

Ikonekta ang database sa Java

How does your Java code talk to the database? Use JDBC — Java Database Connectivity

import java.sql.*;

public class DatabaseDemo {
    public static void main(String[] args) {
        // Database location — SQLite file
        String url = "jdbc:sqlite:Shop.db";
        
        try {
            // Connect
            Connection conn = DriverManager.getConnection(url);
            System.out.println("Connected! ✅");
            
            // Retrieve data
            String sql = "SELECT * FROM Product";
            Statement stmt = conn.createStatement();
            ResultSet rs = stmt.executeQuery(sql);
            
            // Display results
            while (rs.next()) {
                String name = rs.getString("name");
                double price = rs.getDouble("price");
                System.out.println(name + " — ₱" + price);
            }
            
            // Close connection
            conn.close();
        } catch (SQLException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}

📖 Chapter 7 — Good Design Principles 📐

Panuntunan sa maayos na disenyo

Normalization — Avoid Duplication:

Huwag ulit-ulitin ang impormasyon
  • ✅ Separate tables for different kinds of information
  • ✅ Use keys to link tables together
  • ✅ If the same value repeats → move it to its own table
  • ❌ Don't store multiple values in one column

Data Integrity — Keep It Accurate:

Panatilihing tama at buo ang laman
  • ✅ NOT NULL — field cannot be empty
  • ✅ UNIQUE — no duplicate values allowed
  • ✅ FOREIGN KEY — cannot link to something that doesn't exist
