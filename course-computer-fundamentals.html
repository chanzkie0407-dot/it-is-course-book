📖 Chapter 1 — What Is a Computer, Exactly?

Ano ba talaga ang kompyuter?

A computer is a combination of Hardware and Software — two parts that cannot work without each other 💻

Hindi gagana ang isa kung wala ang isa — pisikal na katawan at utos

Hardware ↔ Software

Physical Parts ↔ Instructions & Logic

Hardware = The Physical Parts 🛠️

Pisikal na bahagi — nahahawakan mo
  • CPU — Processor — The brain; follows instructions and does calculations Utak — nagpoproseso ng utos at nagkukuwenta
  • RAM — Memory — Short-term workspace; where active programs live Panandaliang alaala — kung saan tumatakbo ang bukas na programa
  • Storage — Long-term saving; Hard Drive, SSD — keeps data even when powered off Pangmatagalang imbakan — hindi nabubura kahit patayin
  • Motherboard — The bridge connecting all parts together Tulay — nag-uugnay sa lahat ng piyesa
  • Input / Output — Keyboard, mouse, screen, printer Pagpasok at paglabas — nakikipag-usap sa tao

Software = Programs & Instructions 📦

Mga programa — utos na sinusunod ng kompyuter
  • Operating System (OS) — Windows, macOS, Android — manages everything; connects hardware to other software Tagapamahala — nag-uugnay sa piyesa at programa
  • Application — Browser, Word, Games — tools people use for specific tasks Gamit — para sa tiyak na gawain

📖 Chapter 2 — Binary: The Computer's Language 0️⃣1️⃣

Ang wika ng kompyuter — dalawang numero lang

Deep inside, computers understand nothing but 0 and 1 — like a light switch: OFF or ON ⚡

Walang iba — patay o bukas, walang kuryente o mayroon
💡 Bit = Binary Digit
• 0 = OFF / No / False
• 1 = ON / Yes / True
• This is the smallest piece of information Pinakamaliit na yunit — ito ang pundasyon ng lahat

How Computers Count

Paano magbilang ang kompyuter

Humans — Decimal: 0 to 9 → ten digits before repeating
Computers — Binary: only 0 and 1 → two digits before repeating

DecimalBinaryMeaning
00zero
11one
210one-two + zero
311one-two + one
4100four + zero + zero
81000eight + zero + zero + zero

Byte = 8 Bits

8 bits together = 1 byte — enough space for one letter or symbol.

'A' → 01000001
'B' → 01000010
'1' → 00110001

Storage Sizes:

Sukat ng espasyo sa imbakan
  • 1 Byte = 8 bits → 1 character
  • 1 KB (Kilobyte) ≈ 1,000 Bytes → short paragraph
  • 1 MB (Megabyte) ≈ 1 Million Bytes → one photo
  • 1 GB (Gigabyte) ≈ 1 Billion Bytes → thousands of photos
  • 1 TB (Terabyte) ≈ 1 Trillion Bytes → entire library

📖 Chapter 3 — The CPU: The Brain 🧠

Ang Utak — CPU

The CPU does only three things, over and over, billions of times every second:

  1. Fetch — get the instruction from memory Kunin ang utos mula sa memorya
  2. Execute — calculate, compare, move data Isagawa — kuwenta o ilipat ang impormasyon
  3. Next — move to the next instruction Ituloy sa susunod

Fetch → Execute → Fetch → Execute → ... forever ♾️

Speed = Hertz (Hz)

How fast this cycle repeats:
• 1 Hz = 1 time per second
• 1 GHz = 1 Billion times per second ⚡
• Modern CPU = 3–5 GHz → billions of operations in an instant!

Cores = Extra Brains

Dagdag na utak — mas marami, mas sabay-sabay
  • Dual-Core = 2 brains
  • Quad-Core = 4 brains
  • More cores = more tasks handled at the same time ✅

📖 Chapter 4 — RAM vs Storage: Workspace vs Closet 💾

Pagkakaiba ng RAM at Storage — madalas nakakalito

These are NOT the same thing — here's how to tell them apart:

FeatureRAM (Memory)Storage (Drive)
Full NameRandom Access MemorySSD / HDD / Flash Drive
PurposeActive programs running right nowSaving files forever
SpeedExtremely fast ⚡Slower compared to RAM
Survives Shutdown?Everything erased ❌Everything saved ✅
Typical Size8GB, 16GB, 32GB256GB, 512GB, 1TB+
AnalogyYour desk — work here nowYour shelf — store things away
💡 More RAM = more open apps running smoothly at the same time! Mas malaking RAM — hindi bumabagal kahit maraming bukas na programa

📖 Chapter 5 — Software: From Code to Running 💻

Mula nakasulat na code hanggang gumagana ang programa

You write code — how does it turn into something a computer understands?

Two Ways to Translate:

Dalawang paraan ng pagsasalin
  1. Compiler — translates the whole program at once → creates a separate ready-to-run file
    ✅ Examples: Java, C++ Isinasalin lahat nang sabay — nagiging hiwalay na file
  2. Interpreter — translates line-by-line while running
    ✅ Examples: JavaScript, Python Isinasalin habang tumatakbo — bawat linya

Operating System = The Middleman

Ang OS — hindi direktang nakikipag-usap ang programa sa piyesa

Programs never talk directly to hardware — everything goes through the OS:

Program → OS → Driver → Hardware ✅

That's why new hardware needs a driver — it's the translator for the OS.

📖 Chapter 6 — Networks: Connecting Computers 🌐

Pag-uugnay — paano nagpapalitan ng impormasyon

The Internet is just millions of computers sending binary data to each other through wires or waves 🔗

IP Address = Home Address 🏠

Tirahan sa internet — para alam kung saan ipadala

Every device on a network gets a unique number — so data knows where to go.

  • IPv4: 192.168.1.1 — four groups of numbers
  • IPv6: 2001:0db8:... — longer format, for many more devices

Client-Server Model

📱 Client (You) → Ask → 🖥️ Server → Reply → 📱 You

• Client = your browser/app — asks for things
• Server = always-on computer — holds & sends things back
