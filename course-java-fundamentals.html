📖 Chapter 1 — Why Java?

Bakit Java?

Java is one of the most widely used and enduring programming languages — and for very good reason 💪

Isa sa pinakasikat at matagalang ginagamit — may matibay na dahilan
  • Cross-Platform — "Write once, run anywhere" → Windows, Mac, Android, Linux ✅ Isulat nang isang beses — tumakbo sa kahit anong sistema
  • Object-Oriented — organized around reusable components; easier to grow and maintain Nakabatay sa mga bagay — mas madaling palawakin at panatilihin
  • Stable & Widely Used — powers banking systems, enterprise apps, and Android apps Matatag — ginagamit sa bangko, malalaking negosyo, Android
  • Strict & Clear Rules — catches mistakes early; builds strong programming habits Mahigpit ang panuntunan — nakikita agad ang mali, magandang pundasyon
💡 How It Works:
Source Code → Compiler → Bytecode → JVM (Java Virtual Machine) → Runs
Works on ANY device with a JVM — no need to rewrite code! 🌍 Hindi kailangang baguhin ang code — tumatakbo kung saan may JVM

Ihanda ang NetBeans IDE — programa sa pagsusulat ng Java

📖 Chapter 4 — Variables: Data Containers 📦

Lalagyan ng impormasyon — kailangan sabihin ang uri

In Java, you must declare the type BEFORE storing values — it's strictly enforced!

Hindi katulad ng JavaScript — kailangan sabihin kung anong klase

Core Data Types:

Pangunahing uri ng datos
TypeMeaningExample
int Whole number Buong numero 1, -5, 2026
double Decimal number May tuldok na halaga 3.14, 125.50
char Single character Isang titik lamang 'A', '5'
boolean True or False Totoo o Mali true / false
String Text / sentence Maraming titik — teksto "Hello, Java!" 
public class Main {
    public static void main(String[] args) {
        // Pattern: Type name = value;
        String name = "Maria";
        int age = 25;
        double weight = 52.5;
        boolean isStudent = true;

        System.out.println("Name: " + name);
        System.out.println("Age: " + age + " years");
        
        // Update value
        age = 26;
        System.out.println("New Age: " + age);
    }
}
⚠️ Important Rules:
• Uppercase and lowercase are different: age ≠ Age
• String always starts with capital S — unlike the others! Magkaiba ang malaki at maliit na titik — String laging malaki ang S

📖 Chapter 5 — Operations: Doing Calculations ➕

Pagkalkula — matematika sa programa 
public class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 3;
        
        System.out.println("Addition: " + (a + b));      // 13
        System.out.println("Subtraction: " + (a - b));   // 7
        System.out.println("Multiply: " + (a * b));     // 30
        System.out.println("Divide: " + (a / b));        // 3 — whole number only!
        System.out.println("Remainder: " + (a % b));     // 1 — leftover after division
        
        // For decimal precision — use double
        double x = 10.0;
        double y = 3.0;
        System.out.println("Exact division: " + (x / y)); // 3.333...
    }
}

📖 Chapter 6 — Conditions: Making Decisions ⚖️

Kondisyon — magdesisyon ang programa 
public class Main {
    public static void main(String[] args) {
        int score = 85;
        
        if (score >= 90) {
            System.out.println("Excellent! ✅");
        } else if (score >= 75) {
            System.out.println("Passed! ✅");
        } else {
            System.out.println("Needs more practice.");
        }

        // Switch — when checking specific fixed values
        int day = 5;
        switch (day) {
            case 1: System.out.println("Monday"); break;
            case 2: System.out.println("Tuesday"); break;
            case 3: System.out.println("Wednesday"); break;
            case 4: System.out.println("Thursday"); break;
            case 5: System.out.println("Friday"); break;
            default: System.out.println("Weekend");
        }
    }
}

📖 Chapter 7 — Loops: Repeat Without Re-typing 🔁

Pag-uulit — hayaan ang computer ang magsawa 
public class Main {
    public static void main(String[] args) {
        // For Loop — when you know the exact count
        System.out.println("Counting 1 to 5:");
        for (int i = 1; i <= 5; i++) {
            System.out.println("Number: " + i);
        }

        // While Loop — continues until condition becomes false
        int count = 5;
        System.out.println("\nCounting down:");
        while (count >= 1) {
            System.out.println(count);
            count--;
        }
        System.out.println("Go! 🚀");
    }
}

📖 Chapter 8 — Methods: Reusable Code Blocks 🔄

Paraan — pangkat ng utos na may pangalan, tawagin anumang oras

A Method = named block of code — call it whenever you need it ✅

public class Main {
    // Custom method — outside of main
    public static void greet(String name) {
        System.out.println("Good day, " + name + "!");
    }
    
    public static int add(int a, int b) {
        return a + b; // send result back
    }

    public static void main(String[] args) {
        greet("Ana"); // call → Good day, Ana!
        int sum = add(5, 3);
        System.out.println("Total: " + sum); // 8
    }
}

Method Structure Explained:

Bawat bahagi ng paraan — ano ang ibig sabihin 
public static int add(int a, int b) { ... }
│      │      │          │          └── Code that runs
│      │      │          └── Parameters: what you receive
│      │      └── Return type: int = number, void = nothing back
│      └── static = use without creating an object
└── public = accessible everywhere
