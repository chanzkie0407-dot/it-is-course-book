📖 Chapter 1 — Why Start Here?

Bakit ito ang una?

Programming is not just memorizing syntax — it is solving problems. Even if you know every language by heart, without clear thinking you won't build working solutions 💡

Hindi lang pag-alam sa salita — ito ay paglutas ng problema
💡 Simple Analogy:
• Code = pencil and paper
• Logic = your plan and thinking before writing
• No plan → messy, repetitive, hard to finish Ang code ay kasangkapan; ang lohika ay ang plano — walang plano, magulo ang lahat

The Universal 4-Step Problem-Solving Method:

Ang 4-hakbang na paraan sa lahat ng problema
  1. Understand the Problem — What is given? What exactly is the answer needed? Unawain — ano ang ibibigay, ano ang dapat makuha
  2. Make a Plan — How do you get from start to finish? List each step clearly. Magplano — hakbang-hakbang kung paano makukuha ang sagot
  3. Write the Solution — Turn your plan into code. Isulat — gawing programa ang plano
  4. Test & Fix — Is it correct? Any missing cases? How can it be cleaner? Subukan at ayusin — tama ba? may pagkukulang ba?

📖 Chapter 2 — Algorithms: Step-by-Step Plans

Algorithm — malinaw na hakbang-hakbang na utos

Algorithm = clear, unambiguous, ordered instructions — just like following a recipe 📝

Parang resipe — bawat utos malinaw, sunod-sunod, walang kalituhan

Example: Making Tea

❌ Not an Algorithm:
Boil some water, add tea, sugar... done.

✅ This IS an Algorithm:

  1. Fill kettle with 2 cups of water
  2. Place on stove, heat to medium
  3. Wait until boiling (about 2–3 minutes)
  4. Add 1 tea bag
  5. Remove from heat after 3 minutes
  6. Add 2 teaspoons sugar, stir until dissolved
  7. Pour into cup — ready!
Bawat hakbang malinaw — sinong sumunod, pareho ang magiging resulta

In Programming Terms:

Sa paggawa ng programa — ganito ang anyo

Problem: Add two numbers together.

// ✅ Algorithm (plain words first):
1. Receive first number → store in A
2. Receive second number → store in B
3. Sum = A + B
4. Show the result

// In JavaScript:
function add(a, b) {
  return a + b;
}
console.log(add(5, 3)); // 8 ✅

📖 Chapter 3 — Variables: Containers for Information

Variable — lalagyan ng impormasyon

Variable = a named storage box — has a name, holds a value, can be updated 📦

May pangalan, may laman — pwedeng palitan ang laman anumang oras
ConceptExplanationExample
Name What you call it Pangalan — paano tatawagin price, itemCount
Type What kind of data Uri — numero, teksto, totoo/mali Number, Text, Boolean
Value The actual information stored Laman — ang impormasyon sa loob 500, "Maria", true 
// Declare → create the container
let price;

// Assign → put something inside
price = 120;

// Update → replace with new value
price = 150;

// All in one line:

const TAX_RATE = 0.12; // fixed — cannot change ✅

📖 Chapter 4 — Conditions: Making Decisions ⚖️

Kondisyon — magdesisyon ang programa

If... else if... else... — just like choices in daily life!

Kung ganito → gawin ito; kung hindi → gawin iyan 
// Simple decision:
let hour = 14;

if (hour < 12) {
  console.log("Good morning! 🌅");
} else if (hour < 18) {
  console.log("Good afternoon! ☀️");
} else {
  console.log("Good evening! 🌙");
}

Comparison Operators:

Mga simbolo ng paghahambing
SymbolMeaningExample
== Equal value only Pantay ang halaga 5 == "5" → true
=== Equal value AND same type ✅ (prefer this!) Pantay ang halaga AT uri — gamitin ito palagi 5 === "5" → false
!= Not equal Hindi pantay 5 != 3 → true
< / > Less than / Greater than Mas mababa / Mas mataas 10 > 5 → true
<= / >= Less/greater than OR equal to Pantay o mas mababa/mataas 5 <= 5 → true

📖 Chapter 5 — Loops: Repeat Without Re-typing 🔁

Pag-uulit — hayaan ang computer ang magsawa

Never copy-paste code just to repeat something — let the computer handle it! 💪

Huwag ulit-ulitin ang code — hayaan ang programa ang gumawa

For Loop — When You Know the Count:

Alam mo kung ilang beses uulitin 
// Count from 1 to 5:
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
// Output: 1, 2, 3, 4, 5 ✅

While Loop — Until a Condition Changes:

Uulit hanggang magbago ang kalagayan 
let count = 1;
while (count <= 5) {
  console.log(count);
  count++; // ⚠️ NEVER forget this — infinite loop otherwise!
}
⚠️ Infinite Loop = stuck forever
Always make sure your loop has a way to stop — a counter that grows, or a condition that eventually becomes false. Siguraduhin laging may paraan para matapos — kung hindi, nakulong nang walang katapusan

📖 Chapter 6 — Real-World Example: Complete Workflow

Halimbawa sa tunay na buhay — hakbang-hakbang

Problem: Calculate total payment including 12% VAT, with 10% discount if amount is over ₱1000.

Step 1 — Understand:

  • Input: original price
  • If price > ₱1000 → apply 10% discount first
  • Add 12% VAT to the result
  • Output: final amount to pay
Presyo → higit 1000 bawasan ng 10% → dagdag 12% → kabuuan

Step 2 — Plan:

1. Get the original price
2. If price > 1000:
   price = price × 0.90 (subtract 10%)
3. total = price × 1.12 (add 12% VAT)
4. Show total

Step 3 — Code:

function computeTotal(price) {
  // Apply discount first
  if (price > 1000) {
    price = price * 0.90;
  }
  // Then add VAT
  const total = price * 1.12;
  return total.toFixed(2); // keep 2 decimal places ✅
}

console.log(computeTotal(800));  // 896.00 — no discount
console.log(computeTotal(1500)); // 1512.00 — discount applied ✅

📖 Chapter 7 — Debugging: Find & Fix Mistakes 🔍

Paghahanap ng mali — bahagi ng proseso, hindi kabiguan

Mistakes are normal and expected — they teach you! 💜

How to Debug Effectively:

  1. Read the error message — it tells you the line and often what went wrong Basahin ang mensahe — sinasabi kung saan at ano ang mali
  2. Add console.log() — check what each variable holds at every step Ipakita ang laman ng bawat lalagyan — makikita kung saan lumihis
  3. Test with simple known values — use numbers where YOU already know the correct answer Subukan sa simpleng numero na alam mo ang sagot
  4. Read your code aloud — explain it like teaching someone else; gaps become obvious Basahin nang malakas — parang nagtuturo sa iba 
// Debug in action:
function computeTotal(price) {
  console.log('Started with price:', price); // ✅
  
  if (price > 1000) {
    price = price * 0.90;
    console.log('Discount applied →', price); // ✅
  }
  
  const total = price * 1.12;
  console.log('Final total:', total); // ✅
  return total;
}

Problem 1 — Find the Largest Number:

Write a function that accepts three numbers and returns the largest one.

Click to show solution 
// Approach 1 — compare step by step
function largest(a, b, c) {
  if (a >= b && a >= c) return a;
  if (b >= a && b >= c) return b;
  return c;
}

// Approach 2 — use built-in helper (cleaner!)
function largest(a, b, c) {
  return Math.max(a, b, c);
}

Problem 2 — Break Down into Denominations:

Given an amount, show how many ₱100, ₱50, ₱20, ₱10, ₱5, and ₱1 make it up — use largest first.

Click to show solution 
function countBills(amount) {
  const bills = [100, 50, 20, 10, 5, 1];
  const result = {};
  
  for (const bill of bills) {
    result[bill] = Math.floor(amount / bill);
    amount = amount % bill;
  }
  return result;
}

console.log(countBills(187));
// { '100': 1, '50': 1, '20': 1, '10': 1, '5': 1, '1': 2 } ✅
